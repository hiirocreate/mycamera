# MyCamera（自分専用カメラアプリ）

写真・動画撮影 / 8種類のフィルター / 解像度4段階 / シャッター音のオンオフ切り替え
広告なし・ネット通信なし（AndroidManifestにINTERNET権限自体を含めていません）
Android 12（API 31）〜最新バージョンに対応。

---

## 重要：先に正直にお伝えしたいこと

このアプリのコードはすべて用意しましたが、**このクラウド環境はネットワーク制限がかかっており、
Android SDKなどビルドに必要な部品をダウンロードできないため、私の手元で実際にAPKを
ビルド・実機テストすることができませんでした。**

そこで、**GitHub Actions（GitHubの無料の自動ビルドの仕組み）** を使って、あなたのGitHub
アカウント上でビルドしてもらう形にしています。パソコンでのビルド作業（Android Studioの
インストールやコマンド操作）は不要で、下記の手順通りに「ファイルをアップロードして数分待つ」
だけでAPKができあがります。

コード自体は一般的なAndroidアプリの標準的な作り方（WebView + カメラAPI）で書いており、
静的なチェック（XMLの構文確認など）は行っていますが、実機での動作確認はまだできていません。
もし動かない箇所があれば、遠慮なく教えてください。すぐに修正します。

## 手順（コマンド操作なし・すべてブラウザで完結）

### 1. GitHubアカウントを用意する
すでにお持ちであればそのままでOKです。なければ https://github.com/ で無料登録してください。

### 2. 新しいリポジトリを作る
1. GitHubにログイン → 右上の「+」→「New repository」
2. Repository name に `mycamera` などお好きな名前を入力
3. Public でも Private でもどちらでも構いません（Privateなら自分以外は見えません）
4. 「Create repository」をクリック

### 3. ファイルをアップロードする
1. 作成されたリポジトリのページで「uploading an existing file」というリンク（または
   「Add file」→「Upload files」）をクリック
2. お渡しした `mycamera-android-project.zip` を**一度パソコンで展開（解凍）**してから、
   中身のフォルダ・ファイルをすべてまとめてドラッグ＆ドロップ
   （`.github` フォルダも含めて全部アップロードしてください。隠しフォルダなので
   見えにくい場合がありますが、フォルダごとドラッグすれば一緒に入ります）
3. 一番下の「Commit changes」をクリック

### 4. 自動ビルドを待つ
1. リポジトリ上部の「Actions」タブを開く
2. 「Build APK」というワークフローが自動的に走り始めます（数分で完了）
3. 緑のチェックマークが付いたら完了です

### 5. APKをダウンロードする
1. 完了したワークフローの実行結果をクリック
2. 一番下の「Artifacts」欄にある `MyCamera-apk` をクリックしてダウンロード（zip形式）
3. 展開すると `app-release.apk` が出てきます

### 6. スマホにインストールする
1. `app-release.apk` をAndroidスマホに転送（Googleドライブ経由、USBケーブル、メール添付など）
2. スマホ側でそのファイルをタップ
3. 「提供元不明のアプリ」の許可を求められたら許可（初回のみ。設定 →
   このブラウザ/ファイルアプリに「アプリのインストールを許可」）
4. インストール完了後、初回起動時にカメラとマイクの権限を「許可」してください

これで完了です。次回以降アップデートしたい場合も、同じ手順（ファイル差し替え→Actions待つ→
インストール）で上書きインストールできます（署名鍵を固定しているため、データも引き継がれます）。

## 機能

- **写真撮影 / 動画撮影**（音声付き）
- **フィルター8種類**：ノーマル／食べ物／夜景／人物／風景／鮮やか／モノクロ／レトロ
  （プレビュー中にリアルタイムで確認しながら撮影できます）
- **解像度4段階**：4K／2K／フルHD／HD
- **前面・背面カメラ切り替え**
- **シャッター音のオンオフ切り替え**（画面右上の🔔/🔕ボタン。設定は次回起動時も記憶されます）
- 広告なし、ネット接続機能自体を持たないため通信は一切発生しません

## シャッター音について、大事な注意点

このアプリ自身は、ミュートをオンにすれば一切音を鳴らしません（システムのカメラAPIを
直接呼ばず、映像ストリームを取り込んで独自に処理する方式のため、多くの端末では
OS側の強制シャッター音も発生しにくい作りです）。

ただし、**日本国内向けに販売されたスマートフォンの一部（特に大手キャリア経由の機種）は、
盗撮防止のためメーカー・キャリア側でシャッター音を強制的に鳴らす仕組みをハードウェア
（ファームウェア）レベルで組み込んでいる場合があります。** これはSNOWやInstagramを含む
「すべてのアプリ」に共通する制限で、アプリ側からは完全に無効化できません。
プラネタリウムなど静かな場所で使う前に、一度普通の場所で音が鳴らないか確認してから
お使いいただくことをおすすめします。

## フィルターや設定を自分で調整したい場合

`app/src/main/assets/www/app.js` の先頭付近にある `FILTERS`（フィルターの効果）と
`RESOLUTIONS`（解像度の一覧）を書き換えるだけで調整できます。
`css:` の部分はCSSの `filter` プロパティと同じ書き方です
（例: `saturate(1.5) contrast(1.1) brightness(1.1)`）。
書き換えたら再度GitHubにアップロードし、Actionsが自動でビルドし直してくれます。

## 対応バージョン

- 最小: Android 12 (API 31)
- ターゲット: Android 15 (API 35) ※将来もっと新しいバージョンが標準になったら、
  `app/build.gradle.kts` 内の `compileSdk` と `targetSdk` の数字を書き換えるだけで
  対応できます

## 権限について

- `CAMERA`（カメラ映像取得）
- `RECORD_AUDIO`（動画の音声録音）
- `INTERNET` 権限は**含まれていません**。技術的にネットワーク通信ができないため、
  広告表示・データ送信は不可能です。
